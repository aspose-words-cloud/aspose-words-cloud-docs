## Free Support

Aspose provides free technical support through the [community forum](https://forum.aspose.cloud/c/words). All customers, including those evaluating the service, have access. The development team monitors the forum and typically responds within a few hours.

## Paid Support

For priority assistance, use the [Helpdesk](https://helpdesk.aspose.cloud/). For training and implementation support, see [Paid Consulting](https://consulting.aspose.com/).

## Service Status

Check [status.aspose.cloud](https://status.aspose.cloud/) to see if the Words Cloud API is operational or if there are ongoing incidents affecting the service.

The free trial is automatically granted when you [create an Aspose Cloud account](https://dashboard.aspose.cloud/). No credit card required.

## What's Included

- **150 API calls per month** — free, no charges
- **Full API access** — all operations, no feature restrictions
- **No watermarks** — processed documents are clean, with no evaluation stamps
- **Free support** — access the [community forum](https://forum.aspose.cloud/c/words) during evaluation

## Limitations

- 150 API calls per month. See [Pricing Plan](/words/getting-started/pricing-plan/) for paid tiers
- Aspose Cloud is **not HIPAA compliant** — see [HIPAA Policy](https://purchase.aspose.cloud/cloud/policies/hipaa) for details

## Track Your Usage

Monitor your API call consumption and view per-endpoint breakdowns: [Dashboard → Billing → API Usage Logs](https://dashboard.aspose.cloud/#/billing/usage)

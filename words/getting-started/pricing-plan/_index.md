Aspose.Words Cloud uses a single pay-as-you-go plan. One subscription covers all [Aspose Cloud products](https://products.aspose.cloud/). No upgrades or downgrades.

→ [Full Pricing Guide](https://purchase.aspose.cloud/cloud/pricing/) — interactive pricing calculator and current rates

## How It Works

- **150 API calls per month free** — no credit card required
- Billed per API call — not per file or document size. Process as many files as you need
- Monthly invoicing via credit card

## Self-Hosted (Docker)

Self-hosted deployments use the [same pricing model](/words/getting-started/how-to-run-docker-container/). Storage API calls are not billed on self-hosted instances.

## Payment & Cancellation

- Cancel anytime: [Dashboard](https://dashboard.aspose.cloud/) → Billing → Subscription → Downgrade
- [Refund policy](https://purchase.aspose.cloud/cloud/policies/refunds)
- Prices exclude tax. GST applies to Australian customers
